# ProxyEverything

基于 Cloudflare Workers 的实验性通用网页反向代理。

## Try

将 worker.js 部署到 Cloudflare Workers，访问部署域名即可。

## 回归测试

使用 Node.js 22 或更高版本，在仓库根目录运行 `node --test tests/*.test.mjs`。
